# AGENTS.md — simplifytrabaho

A free, open, auto-updated list of jobs at Philippine companies (all roles, all levels,
internships & entry-level featured). PH counterpart of SimplifyJobs/Summer2026-Internships.
Data comes ONLY from public ATS APIs that companies intentionally publish.

**Read before building:** [docs/SPEC.md](docs/SPEC.md) is the full PRD — schemas,
pipeline stages, endpoints, acceptance criteria. [TRACKER.md](TRACKER.md) is the live
work log. [ROADMAP.md](ROADMAP.md) is future scope (don't build it yet).

## Golden rules (legal — never violate, never "just this once")

1. NEVER fetch from LinkedIn, JobStreet, Indeed, Kalibrr, Glassdoor, or any job
   board/aggregator. Their ToS prohibit it.
2. Only the six documented public ATS endpoints in SPEC §5.1 (Greenhouse, Lever,
   Ashby, Workable, SmartRecruiters, Recruitee). No auth bypass, no robots.txt
   violations, no rate-limit evasion.
3. Store facts only: company, title, locations, URL, dates, work setup, structured
   salary. NEVER store job-description text. NEVER store personal data (drop
   recruiter names/emails at normalization).
4. Always link out to the official application page.
5. Politeness: ≥1s between requests, identifying User-Agent
   `simplifytrabaho/<version> (+repo URL)`, max one scheduled full run per day.

## Commands

pnpm ONLY — never npm or yarn (in code, scripts, docs, and CI alike).

```
pnpm install                 # workspace install (root)
pnpm refresh                 # run full pipeline: fetch → data/listings.json → README.md
pnpm --filter web dev        # run the site locally
pnpm --filter web build      # static build (fails on invalid listings.json)
pnpm test                    # all tests
```

Script-naming rule: never name a script `update` or `fetch` — both are pnpm built-ins.

## Repo map

- `pipeline/` — TypeScript CLI. `companies.json` (hand-curated registry — the crown
  jewel) + `src/` (fetchers, normalize, filter, categorize, merge, readme, cli).
- `data/listings.json` — generated source of truth. Committed. Never hand-edit.
- `web/` — Next.js static site reading `data/listings.json` at build time.
- `README.md` — GENERATED by the pipeline. Never hand-edit.

## Conventions

- TypeScript strict mode everywhere; one shared `Listing` type definition.
- Dates: ISO 8601 UTC strings.
- `title` = the role title verbatim as published ("Software Engineering Intern").
- Listings are never deleted — vanished ones get `active: false`.
- Stable sort when writing `listings.json` (company asc, datePosted desc) for
  reviewable git diffs.
- Registry entries need `verified: true` (endpoint confirmed live, per SPEC §7.1)
  before the pipeline uses them.
- Schema changes require updating SPEC §6 first, in the same commit.
